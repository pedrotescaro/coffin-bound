# Coffin Gothic 24

Paleta proposta de 24 cores para Coffin Bound, criada nesta preparação. O arquivo `coffin-gothic-24.gpl` pode ser aberto no LibreSprite. Sombras azuladas e violetas, musgo, pedra, osso, rubi e âmbar mantêm o cenário gótico legível.

O remapeamento usa distância RGB ponderada (2R² + 3G² + B²) sem dithering. Pixels transparentes permanecem transparentes; os valores alpha dos sprites de colisão/efeitos são preservados. A paleta cobre as texturas próprias; branco técnico de fonte e sprite interno do Scribble permanece branco para permitir multiplicação de cor na renderização. Composição translúcida, iluminação e o filtro retro opcional podem produzir cores intermediárias em tela.

Esta padronização visual não comprova nem substitui as licenças dos desenhos originais.
